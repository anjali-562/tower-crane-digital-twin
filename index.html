Physics (STARTER-KIT §1)

M = tipLoad × jibLength = 2.70 × 30 = 81 t·m. cornerRadius = M / maxCapacity = 81 / 5 = 16.2 m. r ≤ corner → 5 t; r > corner → 81 / r; r > jib → null (out of range); r ≤ 0 → 5 t. Never exceeds maxCapacity.
